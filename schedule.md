# 7-Day Full Stack Developer Interview Preparation Plan

Based on your resume, I'll create an intensive 7-day interview preparation plan targeting Fresher / Junior Full Stack Developer positions.

Your main technologies are:

- Frontend: HTML, CSS, JavaScript, TypeScript, React.js, Tailwind CSS.
- Backend: Python, Django, Django REST Framework.
- Database: SQL, SQLite, Django ORM.
- APIs: REST API, Axios, TanStack Query.
- Projects: ShopSphere, QuizMaster, StudyFlow.

The goal is to make you confident in technical interviews, coding rounds, project explanations, and HR rounds within one week.

- Scope and hoisting.
- Closures.
- Callbacks.
